# HotelLuxo

O layout do App Hotel foi personalizado com uma identidade visual direcionada a hotéis e resorts de luxo, incluindo imagens, cores sob medida e a disposição dos elementos em cartões visuais. Criou-se ainda uma nova tela chamada "Sobre", onde são apresentadas informações do projeto, nome do desenvolvedor, versão do sistema, tecnologia utilizada (.NET MAUI) e o ano em que foi desenvolvido. Os elementos discutidos na agenda, como os componentes gráficos e a disposição da interface, foram utilizados para oferecer ao usuário uma experiência mais contemporânea e intuitiva.
